# StatementApp — зачётно-экзаменационная ведомость

Настольное приложение (WinForms, .NET 8) для формирования зачётно-экзаменационных ведомостей.
Разработано по запросу учебной части «Академия ТОП» в рамках учебного проекта

![Главное окно](docs/screenshot-main.png)

## Возможности

- Справочники: дисциплины, группы, студенты, преподаватели (заполняются вручную)
- Формирование ведомости: выбор группы, дисциплины, преподавателя, даты
- Ручной выбор студентов, которые попадают в ведомость
- Редактирование часов по плану и учебного года прямо в ведомости
- Выставление оценок: цифрой, «Зачтено / Не зачтено», «Неявка», «Не допущен»
- Проверка ведомости перед закрытием
- Экспорт в `.docx` по форме колледжа (печать выполняется из Word)
- Хранение данных в JSON, база данных не нужна

## Архитектура

Архитектура (разделение на слои и паттерн MVP) предоставлена преподавателем [ФИО].

| Проект | Назначение |
|---|---|
| `StatementApp.Core` | Сущности, перечисления, валидаторы, интерфейсы |
| `StatementApp.Data` | Хранение в JSON, генерация `.docx` |
| `StatementApp.UI` | Формы (View), презентеры (Presenter), точка входа |

Зависимости подключаются через DI (`Microsoft.Extensions.DependencyInjection`).

## Технологии

C#, .NET 8, Windows Forms, System.Text.Json, Microsoft.Extensions.DependencyInjection

## Запуск

**Готовый exe:** скачайте `StatementApp.UI.exe` из раздела [Releases](../../releases) и запустите.
Требуется Windows 10/11 x64.

**Из исходников:**
1. Установите Visual Studio 2022/2026 с рабочей нагрузкой «Разработка классических приложений .NET»
2. Откройте `StatementApp.sln`
3. Запустите проект `StatementApp.UI`

## Где хранятся данные

`%AppData%\StatementApp\data.json`

Чтобы перенести данные на другой компьютер, скопируйте этот файл в ту же папку.

## Сборка exe

```
dotnet publish StatementApp.UI -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
